### 1.1 系统定位
本系统是一个基于 **Vue3 + Vite** 构建的在线留言反馈平台，为用户提供留言提交、浏览、管理等功能。系统支持普通用户和管理员两种角色视图，实现了完整的留言生命周期管理。

```html
  </button>

```

**删除处理逻辑：**
```javascript
// 来源: App.vue:60-73
async handleDelete(id) {
  if (!confirm('确定要删除这条留言吗？')) {
    return
  }
  try {
    const response = await api.delete(`/messages/${id}`)
    if (response.code === 200) {
      alert('删除成功')
      this.fetchMessages()
    } else {
      alert('删除失败: ' + response.message)
    }
  } catch (error) {
    alert('删除失败，请稍后重试')
  }
}
```

### 4.2 分页加载逻辑

```javascript
// 来源: App.vue:33-46
async fetchMessages() {
  this.loading = true
  try {
    const response = await api.get('/messages', {
      params: {
        page: this.currentPage,
        size: this.pageSize,
        isAdmin: this.isAdminView || undefined
      }
    })
    if (response.code === 200) {
      this.messages = response.data.records || []
    }
  } catch (error) {
    console.error('获取留言失败:', error)
  } finally {
    this.loading = false
  }
}
```

### 4.3 视图切换逻辑

```javascript
toggleAdminView() {
```

### 4.4 表单提交流程

```javascript
// 来源: App.vue:48-58
async handleSubmit(formData) {
  try {
    const data = {
      ...formData,
      isAdmin: this.isAdminView  // 根据当前视图设置留言类型
    }
    const response = await api.post('/messages', data)
    if (response.code === 200) {

    } else {
      alert('提交失败: ' + response.message)
    }
  } catch (error) {
    alert('提交失败，请稍后重试')
  }
}
```
